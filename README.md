# সেতু

HTML থেকে প্লে স্টোরের অ্যাপ ফাইল (AAB) বানানোর ধাপে ধাপে সহজ সঙ্গী।

## ফোনে নামানোর নিয়ম
1. GitHub-এ নতুন repository খুলুন, নাম: `setu` (Public)।
2. Upload files দিয়ে ৬টি ফাইল দিন: index.html, manifest.json, sw.js, icon-192.png, icon-512.png, README.md → Commit।
3. Settings → Pages → Branch: main, Folder: /(root) → Save।
4. লিংক: https://আপনার-ইউজারনেম.github.io/setu/
5. ফোনের Chrome-এ খুলে ⋮ মেনু → Install app বা Add to Home screen।
